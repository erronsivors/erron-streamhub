Политика конфиденциальности Crossember

Действует с 10.11.2026

Коротко

Crossember — программа, которая работает только на вашем компьютере. У неё нет своего сервера. Разработчик не получает и не хранит ваши данные.

Какие данные используются

  • Вход в YouTube (Google). После вашего согласия Google выдаёт программе токен доступа. С ним Crossember находит ваш текущий эфир, читает чат, суперчаты и спонсорства, показывает число зрителей. По вашему действию он отправляет сообщения в чат, удаляет сообщения и банит пользователей.
  • Вход в Twitch работает так же, через официальный вход Twitch.
  • VK Видео Live, GoodGame, Kick. Читаются публичные данные канала, который вы указали, без входа.

Где хранятся данные

  • Токены входа шифруются средствами Windows и хранятся только на вашем ПК.
  • Сообщения чата на диск не записываются. На ПК остаются только события (подписки, донаты и т. п.) для истории и статистики.
  • Ваш пароль Google или Twitch программа не видит: вход идёт на странице самой площадки.

Передача третьим лицам

Crossember никому не передаёт и не продаёт ваши данные. Запросы идут напрямую с вашего ПК в API площадок: YouTube Data API, Twitch и другие. Использование данных из API Google соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

  • В Crossember: «Подключения» → площадка → «Выйти». Токены удаляются с ПК.
  • В аккаунте Google: myaccount.google.com/permissions → Crossember → «Удалить доступ».
  • Удаление программы вместе с папкой данных стирает всё, что она хранила.

English summary

Crossember is a desktop app that runs only on your computer and has no server of its own. OAuth tokens (Google/YouTube, Twitch) are encrypted with Windows DPAPI and stored locally. They are used only to read your live chat and stream info, and to send, delete or moderate chat messages at your request. No data is collected, shared or sold by the developer. Crossember's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access in the app ("Выйти") or at myaccount.google.com/permissions.
