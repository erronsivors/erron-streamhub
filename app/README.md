# Crossember (app)

Личный мульти-хаб стримера. ТЗ и этапы — `../ТЗ.md`.

## Запуск
```
npm install      # один раз
npm run dev      # режим разработки (горячая перезагрузка)
npm run build    # сборка в out/
npm start        # запуск собранной версии
npm run typecheck
```

## Что есть (этап 0)
- Окно в стиле ERRON: Главная, События, Оверлеи, Подключения (диагностика + журнал), Настройки.
- Подключение к OBS (obs-websocket v5): сцена, эфир, запись, разрешение/FPS, авто-переподключение.
  OBS → Инструменты → Настройки WebSocket-сервера → включить, скопировать пароль → «Подключения» → OBS.
- Сервер оверлеев `127.0.0.1:47832`, оверлей алертов (тестовые события из «Событий»).

## Безопасность
- Electron: contextIsolation + sandbox, без nodeIntegration, CSP, запрет навигации/окон/разрешений, IPC только от своего окна.
- Секреты: `safeStorage` (Windows DPAPI) в SQLite; без шифрования не сохраняются.
- Сервер: только loopback, ключ в каждой ссылке/WebSocket (сравнение за постоянное время), проверка Host и Origin.
- Оверлеи выводят пользовательский текст только через `textContent`.

## Где данные
`%APPDATA%\erron-streamhub\data\hub.sqlite3` (настройки, события, зашифрованные секреты).
